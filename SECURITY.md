# Security Policy

## Reporting a Vulnerability

Please report security issues privately. Do **not** open a public issue.

- **Preferred:** GitHub private vulnerability reporting — Security tab →
  "Report a vulnerability" (https://github.com/craigmbrown/ethonline-sealed-bid/security/advisories/new)
- **Alternative:** email craigmbrown@gmail.com with subject `[SECURITY] ethonline-sealed-bid`

Include the affected component, reproduction steps, and impact.

## Response

- Acknowledgement within 72 hours
- Triage and severity assessment within 7 days
- Fix or mitigation for confirmed High/Critical issues targeted within 30 days

## Disclosure

Coordinated disclosure: please allow time to remediate before publishing.
Reporters are credited unless they ask to stay anonymous.
